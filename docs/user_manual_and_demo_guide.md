# User Manual and Project Demonstration Guide

This guide provides step-by-step instructions for running, testing, and demonstrating the **Ransomware Behavior Detection and Classification via Graph Neural Networks (API Call Graphs)** system.

---

## 1. Prerequisites and Installation

### A. Environment Requirements
- **Python:** 3.11+
- **Node.js:** v20+ / v24+
- **Operating System:** Windows, Linux, or macOS

### B. Python Environment Setup
From the project root (`ransomware-gnn-cicd`):

```bash
# If using uv (recommended for ultra-fast user-space setup)
uv venv .venv --python 3.11
source .venv/bin/activate  # Or on Windows PowerShell: .\.venv\Scripts\activate
uv pip install -r requirements.txt

# Or with standard pip:
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### C. Frontend Build Setup
```bash
cd frontend
npm install
npm run build
cd ..
```

## 2. Launching the System

### Option 1: Unified Full-Stack Application (Recommended)
FastAPI automatically serves the compiled production React dashboard at `http://127.0.0.1:8000/`:


## 3. Step-by-Step Demonstration Script for Project Guides

Follow this sequence during your project evaluation or viva demonstration:

### Step 1: System Overview & Dataset Corpus (Tab: "Overview Dashboard")
- **Action:** Open the dashboard.
- **Explain to Guide:** Point out the stat cards showing the 240 structured traces in the corpus (100 Benign, 40 Suspicious, 100 Ransomware across 14 realistic families).
- **Highlight:** The held-out test accuracy (100.0%) and low average inference latency (2.84 ms), demonstrating real-time capability for CI/CD gates.

### Step 2: Dynamic Behavior & Early Warning Analysis (Tab: "Sample Analysis")
- **Action:** Select a ransomware sample (e.g., `RANSOM_0001_LockBit3-Sim`) from the top sample dropdown.
- **Explain to Guide:** Show the **Pre-Attack Early Warning Trajectory**.
- **Key Point:** Point out that at **10% of execution**, before destructive file encryption begins, the GNN model detected the threat with a high risk score, providing **27+ ms of lead time** before any `.locked` file was created.
- **Trace Stream:** Scroll down to show the chronological API stream with sensitive PASAC calls (`vssadmin delete shadows`, `CryptAcquireContext`, `FindFirstFile`) color-coded in rose.

### Step 3: Interactive Directed API Call Graph (Tab: "API Call Graph Explorer")
- **Action:** Switch to the Graph Explorer.
- **Explain to Guide:** Explain the multi-relational graph topology:
  - Nodes represent API invocations color-coded by 9 functional categories.
  - Edges capture sequential flow, intra-thread continuity, and shared resource dependencies.
- **Action:** Use the zoom controls and filter by category (e.g., filter to "Cryptography" or "Defense_Evasion").

### Step 4: GNN Architecture Comparison (Tab: "Model Performance & ROC")
- **Action:** Open Model Performance.
- **Explain to Guide:** Review the comparative evaluation table comparing **GAT, GCN, GraphSAGE, and Random Forest**.
- **Interactive Feature:** Click the **GAT**, **GCN**, and **GRAPHSAGE** buttons at the top to toggle the active inference backbone in real time and inspect the confusion matrix on the held-out test split.

### Step 5: Explainable AI & Critical Subgraphs (Tab: "GNN Explainability")
- **Action:** Switch to GNN Explainability.
- **Explain to Guide:** Show the **Saliency Narrative** generated by gradient-based attribution (inspired by GNNExplainer).
- **Table:** Review the top influential API calls ranked by attribution score, highlighting why the model made the classification.

### Step 6: CI/CD Supply Chain Screening Simulation (Tab: "CI/CD Supply Chain Gate")
- **Action:** Open the CI/CD panel.
- **Simulation 1 (Benign):** Click **"Screen Benign Artifact"** -> Point out the **PASS** gate decision (Risk Score < 40).
- **Simulation 2 (Ransomware):** Click **"Screen Ransomware Artifact"** -> Point out the **BLOCK** decision (Risk Score = 100/100) and the specific policy rule violations (`RULE-SEC-01: Risk score exceeds threshold`, `RULE-SEC-02: vssadmin shadow copy deletion`).
- **Audit Table:** Scroll to the **Immutable Security Audit Trail** showing the recorded decisions.

### Step 7: Reports and Project Defense (Tab: "Reports & B.Tech Defense")
- **Action:** Open Reports.
- **Action:** Click **"Download Markdown Report"** to export a formatted security audit report.
- **Summary:** Review the B.Tech Major Project Defense Briefing Sheet summarizing the research gap, GNN topology, and advantages over baselines.
